# BEAST

BEAST (Bayesian Exascale Atmospheric Swin Transformer) is a PyTorch library for
building and training probabilistic weather models that run across thousands of
GPUs. It provides the model, its layers, the loss, ERA5 datasets and evaluation
metrics; you bring the training loop.
