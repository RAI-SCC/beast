## Installation

### From source

1. Clone the repository

```console
git clone https://github.com/RAI-SCC/beast.git
```

2. Initialize and update the submodules

```console
git submodule init
git submodule update --remote --recursive
```

2. Install with pip or your prefered package manager

```console
pip install .
```

For development:

```console
pip install -e .[dev]
```
