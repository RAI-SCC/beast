### Models

#### Bayesian ViT

 - Vision Transformer converted to a Bayesian neural network
 - currently implemented with DTP

#### SWIN model

 - Pangu / Kangu based weather model using a 2D SWIN Transformer processor and convolutional patch embedding and recovery
 - currently implemented with DP

#### NICE SWIN model

 - same as the SWIN model, but with Noise Input Conditioning for Emsembles (NICE), as inspired by FGN
